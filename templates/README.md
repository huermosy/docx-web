# 文档模板

本目录存放预设模板和自定义模板。

## 预设模板

### default_zh.dotx (中文默认模板)
- 纸张：A4 (21cm x 29.7cm)
- 页边距：上下 2.54cm，左右 3.18cm
- 正文字体：宋体，小四（12pt）
- 标题字体：黑体
- 行距：1.5倍，首行缩进：2字符

### default_en.dotx (英文默认模板)
- 纸张：Letter (8.5in x 11in)
- 页边距：上下 1 inch，左右 1.25 inch
- 正文字体：Times New Roman，12pt
- 行距：1.5倍，首行缩进：0.5 inch

## 自定义模板
上传后系统将严格对照模板规范检查文档格式。
支持格式：.dotx, .dot, .docx, .doc
